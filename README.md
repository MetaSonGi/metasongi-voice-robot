# MetaSonGi Voice Robot


Unity 가상 로봇과 실제 로봇을 같은 명령 체계로 제어하는 음성 AI 프로젝트입니다.


## 현재 상태

Unity 가상 로봇 조작, 브라우저 음성·텍스트 입력과 로컬 명령 큐를 추가했습니다. 실제 로봇은 DryRun 전송 인터페이스만 제공하며 모터를 제어하지 않습니다. 대상 기종별 어댑터 구현이 필요합니다. Unity 컴파일·장비 검증은 아직 하지 못했습니다.

## 빠른 실행

```bash
python setup_unity.py
```

자세한 실행 순서와 구현 제한: [RUN.md](RUN.md) · 검증 결과: [VALIDATION.md](VALIDATION.md)

## 전체 개발 로드맵 (아래 항목은 최종 목표)
- [ ] 마이크 입력과 한국어 음성 인식
- [ ] 자연어를 구조화된 로봇 명령으로 변환
- [ ] 가상 로봇 어댑터와 실제 로봇 어댑터 분리
- [ ] 이동·집기·놓기·초기 자세·정지 명령
- [ ] 명령 상태와 실행 로그 표시


## 개발 순서
1단계: 텍스트 명령과 가상 로봇 → 2단계: 음성 입력 → 3단계: 대상 실제 로봇 선정과 통신 검증 → 4단계: 제한된 실제 동작.


## 설계와 프로젝트 경계
AI 출력 → 명령 스키마 검증 → 관절·속도·작업영역 제한 → 실행 어댑터로 구성합니다. 실제 로봇은 모델과 제어 인터페이스가 정해지기 전까지 연결 완료로 간주하지 않습니다. 하드웨어 실행은 기본 비활성화하고 물리 비상정지를 별도로 둡니다.
